# SARI iOS — Stage 14C

Independent native iOS/iPadOS project track.

Design rules from this stage onward:
- Swift / SwiftUI only for the app UI.
- Adaptive layouts: compact and regular horizontal size classes.
- Dynamic Type; avoid fixed text heights.
- Safe Area support including modern iPhone cutouts/Dynamic Island.
- RTL/LTR support and multilingual text expansion.
- iPhone and iPad layouts should use available width rather than stretch phone UI.
- SARI visual identity: emerald/deep green, restrained gold accents, calm Quran surfaces, distinct travel and fiqh personalities.
- iOS changes must not modify the Android project.

Stage 14C next UI pass: Quran, Adhkar, Fiqh, Travel, Weather, Qibla, Settings.
